# Decision Protocol (Pre-Registered)

Register this file before the first run. After run one, any change requires a dated entry in the change log below and never applies retroactively. Purpose: fix the decision rules before seeing results, so no outcome can be argued into a preferred conclusion.

## Baseline freeze

Baseline B is the committed staged corpus: commit `cd58ed4`. Until a Phase 3 decision fires, canonical rule prose does not change; wording concerns go to the candidate-revision ledger, not into files.

## Arms

- **A, no rules:** checkout with `AGENTS.md`, `CLAUDE.md`, `.agents/skills/`, and all canonical directories removed.
- **B, frozen corpus:** the baseline commit, unmodified.
- **C, minimal kernel:** [arms/kernel-c.md](arms/kernel-c.md) as the sole instruction file.
- **D, abstract paragraph:** [arms/paragraph-d.md](arms/paragraph-d.md), negative control, subset only.

## Phases

- **Phase 0, routing pilot (gate).** B only, on every target agent surface (at minimum Claude Code and one Codex surface): S05, S07, and C01, one rep each. Record every rule file actually read, from transcripts or tool logs. Gate: if under 80% of route-expected files load on a surface, fix routing or adapters for that surface and repeat Phase 0. Until the gate passes, do not start Phase 1 and do not remove any redundancy, including skill completion paragraphs.
- **Phase 1, guardrail grid.** Scenarios S01 to S14, arms A, B, C, 3 reps: 126 runs, scored with the [behavioral score](rubrics/behavioral-score.md).
- **Phase 2, capability grid.** Tasks C01 to C06, arms A, B, C, 3 reps: 54 runs per the [capability suite](capability/README.md). Arm D: S02, S05, S07, S09 plus C01, 2 reps: 10 runs.
- **Phase 3, ablations.** Per [ABLATION-MAP.md](ABLATION-MAP.md), triggered arms only.

## Recorded per run

Arm (in the result template's Condition field), agent surface, model, fixture revision, rubric scores, critical failures, and cost covariates: instruction tokens loaded, total tokens, tool calls, wall-clock time, process artifacts produced. Invalid runs (broken fixture, evaluator hint, surface outage) are recorded and rerun, never counted as pass or fail.

## Decision rules, fixed in advance

1. **Default.** B remains the shipped system unless a rule below fires.
2. **Adopt C** only if all three hold: guardrail mean pass rate within 5 points of B with no critical-failure class that C exhibits and B does not; pairwise capability record against B at least even; at least 30% fewer loaded instruction tokens.
3. **Prune a B file** only through its ablation trigger and prune criteria in the map.
4. **Apply a candidate revision** only if its linked scenario fails in the predicted mode in at least 2 of 3 B reps. After the edit, rerun that scenario and its cluster's mapped scenarios.
5. **Claims.** Results support only "on these scenarios, models, and surfaces". Any broader tendency claim requires replication across at least two model families and at least two agent surfaces.
